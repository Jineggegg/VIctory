# 三档负载的进程峰值

每档 6 对，使用合并纹理后的同一基线及本地候选。每次另起一个 Windows 进程运行同一个 writeback(host, pages)，包括原版的逐字节验证。两臂添加相同的测试入口。普通构建间隙采集，仅用于分析内存。变化量为同对候选减基线的字节数中位数，95% 区间按整对重抽 5000 次。六对样本的区间较粗。[36 个进程原始值](scale.json)
