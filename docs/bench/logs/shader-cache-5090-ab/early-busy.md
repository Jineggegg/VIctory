# Windows 文件正被占用时的 PSO 持久化

每个版本先实际预建 64 个计算 PSO 并保存。只更新 early list 时，记录写入大库文件的实际字节数。另在 Windows 上持有拒绝替换的库文件句柄，添加第 65 个 PSO 后保存；一个进程用已落盘的 early list 验证新标记，另一组在同一进程关闭句柄并再保存，然后重新启动检查第 65 个 PSO 是否从库载入。每项各三次，计时为普通间隙校准。
