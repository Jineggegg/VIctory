## 初筛

分层数据库在同一应用的前 32 个新条目上使用普通文件，后续写入 SQLite WAL。新进程的同一冷写用例中，2,000 个条目的中位数从 1,168.641 ms 降到 521.121 ms，配对下降 55.53%。从盘上打开该库并读取第 1001 至 1020 个条目，中位数从 1.422 ms 增至 6.385 ms，配对增加 347.12%，家族区间 [+315.23%, +375.40%]。冷写工作集峰值增加 4.66%，家族区间 [+2.70%, +5.34%]。该方案因稀疏读取和内存回归淘汰，未合入选择交付的源码。这个定向场景只运行 shader 工作负载；前表大档还包含其他 GPU 工作，两个场景的绝对耗时各自比较。[四个新进程的 15 对原始数据](tiered-reopen-screen15/paired.json)

VIctory #2787 的 4,000 个预建键都与原流程一致。该步骤的 15 对配对中位耗时下降 90.20%，家族区间 [−90.32%, −89.91%]。场景也执行寄存器包匹配，单用 #2787 时这项的配对变化为 −0.31%，家族区间 [−0.91%, +1.00%]。[预建键初筛](2787-screen15/paired.json)
