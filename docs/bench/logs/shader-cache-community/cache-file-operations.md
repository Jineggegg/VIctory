# 写入 20 个 shader 时的文件操作

对 69e564e 基线和仅修改磁盘布局的 7b3464a 插入相同的计时点。每组重新启动 Windows 进程、使用空目录，先跑两对预热，再交替保留 30 对。每次检查 20 个条目并计算相同的 DXIL 集合摘要。以下时间来自带计时代码的非独占实验。

| 单个条目，微秒 | 基线中位 / p95 / p99 | 平铺中位 / p95 / p99 |
|---|---:|---:|
| 目录创建或检查 | 129.30 / 240.60 / 310.30 | 0.00 / 0.00 / 0.00 |
| 创建临时文件 | 87.40 / 134.60 / 182.00 | 116.35 / 213.30 / 257.10 |
| 写内容 | 40.90 / 68.30 / 85.00 | 41.80 / 68.20 / 96.50 |
| 关闭句柄 | 24.00 / 38.00 / 61.90 | 18.60 / 32.80 / 44.90 |
| 重命名发布 | 163.70 / 226.60 / 299.70 | 165.35 / 278.90 / 360.20 |

| 每批，毫秒 | 基线中位 / p95 / p99 | 平铺中位 / p95 / p99 |
|---|---:|---:|
| 目录创建或检查 | 2.768 / 3.527 / 3.983 | 0.000 / 0.000 / 0.000 |

平铺方案在开始使用缓存时创建翻译器目录，单条目的目录阶段为零。基线在每个发布前创建或检查分片目录。基线在重命名前关闭临时文件，平铺方案在重命名后关闭它。批次计时包含翻译、读取尝试、编码等其他开销。测试没有记录 Windows Defender 或其他过滤驱动的事件，无法把长尾归因于某个进程。原始时间分辨率以纳秒记录，共 1,200 行。
